### V29.1 修改（2026-11-02）

1. **社区视频投稿的权属确认**：附件变化后仍要求重新确认权属（原有设计，保留）。现在勾选框会被高亮并给出提示；提交时如果缺少确认，会自动跳到勾选框；已加入草稿的视频在上传列表里显示“已加入草稿”，不再提供重复的“加入当前草稿”。
2. **四轨循环录制按工程小节数自动停止**：时长按“速度 × 拍号 × 小节数”计算，和“按工程长度循环”回放用的是同一个公式；提前点停止也会照常保存。
3. **浏览器英文报错本地化**：麦克风、摄像头、MIDI、蓝牙等设备报错不再直接显示浏览器英文原文，改为四种语言的原因说明（原始信息保留在错误对象中，便于排查）；带“：”的提示，冒号后的原因也会翻译。

`SOURCE-MANIFEST.json` 仍是 V29 原始源码的校验清单；V29.1 和 V29.2 的改动见 Git 提交记录。

## 手机在线预览

<https://claude.ai/artifact/9rJcYr7ohYTN1fnpp6sAbT>（claude.ai 私有链接，手机浏览器或 Claude App 可直接打开；分享给他人需在页面的“分享”菜单中授权）

V29 客户端和**原样的服务端接口代码**都在浏览器里运行：数据库用纯 JavaScript 版 SQLite（sql.js 的 asm.js 构建，见 `tools/online-preview/vendor/`），媒体存在 IndexedDB，App 发出的 `/api/` 请求在本页内处理，不会发到任何服务器。所有数据只保存在当前浏览器。

- 可用：曲库、练习示范、伴奏、学习路径与动作跟练、课程云进度、音色与预设云备份、MIDI、节拍器、调音参考音、社区发帖 / 短视频 / 点赞评论、后台审核（页面左下“在线预览”→“打开后台”）、导出记录与作品包（保存前会请你确认；.mid 等格式会打包成 .zip）
- 不可用：麦克风和摄像头（调音器检测、跟奏、录音录像）、离线模式、蓝牙 MIDI。这些请用下面的一键预览

## 一键预览

在电脑上启动完整的 App：客户端、服务端接口、本地数据库和后台管理端一起运行，浏览器自动打开。

| 系统 | 操作 |
|---|---|
| Windows | 双击 `一键预览.cmd` |
| macOS | 双击 `一键预览.command`（首次需在“系统设置 › 隐私与安全性”中允许） |
| 任意系统 | 在仓库根目录运行 `node start-preview.mjs` |

需要 Node.js 22.5 或更高版本（建议 24 LTS），无需 `npm install`。启动后：

- App：<http://127.0.0.1:18912/>
- 后台：<http://127.0.0.1:18912/admin>
- 身份：本机测试管理员 `preview-owner`，所以社区发帖、云备份、课程云进度和后台审核都能直接使用；在 App 里也可以切回访客
- 数据：保存在 `web-source/.preview/`，重启后保留

常用参数：`--port 18920` 换端口，`--role user` 或 `--role anonymous` 换成普通账号或未登录访客，`--reset` 清空本地预览数据，`--no-open` 不自动打开浏览器，`--help` 查看全部。

预览只监听本机 `127.0.0.1`，手机无法直接访问；麦克风、摄像头只在 `localhost` 或 HTTPS 下可用。手机上请使用线上客户端。

### 功能验收

`tools/acceptance.cjs` 会自动启动一个独立的预览实例（数据在 `web-source/.preview/acceptance/`），用 Chromium 模拟手机、生成 440 Hz 麦克风信号和虚拟摄像头，逐项操作 37 个功能点，结束后关闭实例：

```sh
npm i -D playwright && npx playwright install chromium   # 首次
node tools/acceptance.cjs
node tools/text-audit.cjs     # 界面文字检查（漏翻译、过期版本号、内部说明），结果写入 docs/文字检查结果.json
```

最近一次结果见 [`docs/一键预览验收结果.json`](docs/一键预览验收结果.json)：37 / 37 通过，页面脚本错误 0。覆盖首次引导、曲库、练习与麦克风跟奏、伴奏、动作跟练与课程云进度、学习路径、录音 / 录像 / 四轨、音色与预设云备份、MIDI 导入导出、调音器判准、节拍器、社区发帖 / 短视频 / 点赞评论、后台审核与九个管理页、导出与作品包恢复、离线断网、语言与主题、乐器切换、访客切换。

蓝牙 MIDI 和真实小提琴需要实体设备，验收只确认了入口会给出明确提示。

## 手动运行

一键预览做的就是下面这些步骤：

```sh
cd web-source
node scripts/build-worker.cjs   # 生成 dist/server/index.js，打包 149 个静态资源
node --test tests/*.test.mjs    # 723 项自动化测试
node scripts/preview.mjs        # http://127.0.0.1:18912
```

原说明要求 Node.js 24；本次在 Node.js 22.22 上构建与测试也全部通过。`dist/` 本身是静态 PWA，可直接用任意静态服务器打开 `web-source/dist/index.html`，此时社区、账号、在线课程目录和云进度接口不可用（`/api/*` 返回 404），其余本机功能和离线缓存可正常使用。
